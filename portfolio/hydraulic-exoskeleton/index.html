    Hydraulic Full-Body Exoskeleton Control with Mission Payloads

    Research Engineer · Jan. 2025 – Jan. 2026
    LIG Defense & Aerospace

    Overview

    This project developed control and validation components for a hydraulic full-body exoskeleton intended to assist walking with mission payloads.

    Exoskeleton hardware and lower-body sensor configuration reported in the related peer-reviewed publication.

    Control Architecture

    The upper layer generated gait-phase-dependent desired joint forces: load-support commands during stance and gravity-compensation commands during swing. A model-free PID loop then mapped each desired force to the corresponding hydraulic-cylinder command.

    Contributions

    • Developed gait-phase-dependent hydraulic force control for stable walking, including load-support commands during stance and gravity compensation during swing
    • Implemented lower-level, model-free PID control that mapped desired joint forces to hydraulic cylinder commands
    • Developed FFT-based discrimination between wearer–exoskeleton interaction forces and external impacts for active balance control
    • Built a GUI for real-time monitoring and high-rate data logging during controller validation

    Scope

    The project combined high-level force-command generation, low-level hydraulic actuation, and validation infrastructure. Only publicly documented research descriptions are shown; hardware specifications, source code, and internal media are omitted.

    Related Publication

    The frequency-domain disturbance-discrimination work contributed to a peer-reviewed paper on postural stabilization for protective-mission lower-extremity exoskeleton operation. The publication studies balance monitoring, virtual-spring stabilization, and FFT-based distinction between voluntary interaction and unexpected external impacts.
